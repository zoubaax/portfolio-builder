I want to build an AI-powered portfolio builder, inspired by products like Lovable, but focused specifically on creating professional personal portfolios.

The user should be able to describe themselves in natural language, upload their CV, connect their GitHub account, or manually provide their information. The AI agent should understand their profile and generate a complete, modern, responsive portfolio website.

The platform should include an AI chat interface where users can continuously request changes to their portfolio, such as changing the design, rewriting sections, adding projects, removing sections, changing colors, improving the layout, or making the portfolio more professional.

The generated portfolio should be based on a structured portfolio system and reusable components, allowing the AI to modify the portfolio reliably instead of generating an entirely new website every time.

Core features:

* AI-generated portfolio from a prompt
* CV upload and information extraction
* GitHub integration to import projects and profile information
* Manual editing of portfolio content
* AI chat for modifying the portfolio
* Live visual preview
* Multiple professional portfolio styles/templates
* Responsive design for desktop and mobile
* Portfolio sections such as Hero, About, Skills, Projects, Experience, Education, and Contact
* Portfolio version history and the ability to restore previous versions
* Publish the portfolio online
* Give every user a personalized subdomain such as `username.yourplatform.com`
* Support custom domains later
* Export the complete portfolio source code as a ZIP file
* Allow users to connect GitHub and export the portfolio to their own repository
* Generate a README and clean, understandable project structure
* Users should own and be able to access their generated source code

The product experience should feel similar to an AI coding/building agent: the user explains what they want, the agent builds the portfolio, the user sees the result immediately, and they can continue chatting with the agent to improve it.

The main goal is to make creating, customizing, publishing, and owning a professional portfolio extremely simple, even for users who do not want to build the website manually.

The product should focus on the complete journey:

Describe yourself → Import your information → Generate portfolio → Edit with AI → Preview → Publish → Get your subdomain → Export/own your source code.
